# 📧 Business Email Writer - WCA AI Tool

## 📌 Project Overview

This project is an AI-powered email generator designed to help users quickly create professional business emails. It simplifies email writing by allowing users to enter a few details and receive a complete, well-structured email instantly.

## 💡 What This Tool Does

This tool uses artificial intelligence to generate professional emails.

The user provides:

* The purpose of the email
* The recipient
* The tone (Professional, Formal, or Friendly)

The system then generates:

* A suitable subject line
* A complete email body

Finally, the system adds a professional signature to the email.

---

## ⚙️ How It Works

1. The user enters the required details
2. The system sends the information to an AI model
3. The AI processes the request and generates an email
4. The final email is displayed to the user
